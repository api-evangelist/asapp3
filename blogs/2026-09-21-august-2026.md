Scenario Creation from Production Conversations - GenerativeAgent Test Scenarios can now be built from production conversations. In a conversation where GenerativeAgent behavior needs fixing, click Create Scenario and select the branch where the test should be created. The test is created automatically, including the description, mock data, customer goals, and evaluations pulled from the conversation.
