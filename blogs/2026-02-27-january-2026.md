Omni-channel Tooling Optimization (OCTO) - GenerativeAgent OCTO allows a single task to be used across voice and chat channels, streamlining GenerativeAgent configuration management. Unified task management for both channels with the ability to edit procedures, voice settings, and chat settings in one place. MCP Server Integration - GenerativeAgent Connect GenerativeAgent to Model Context Protocol (MCP) servers to access a wider range of language models and enhanced capabilities.
